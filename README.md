# जनहुंकार न्यूज़ — शुरुआती वेबसाइट पैकेज

## शामिल सुविधाएँ
- मोबाइल-अनुकूल हिंदी न्यूज़ होमपेज
- एडमिन लॉगिन
- खबर लिखना, फोटो अपलोड करना, प्रकाशित/ड्राफ्ट करना और डिलीट करना
- रिपोर्टर का डिफ़ॉल्ट नाम: Alisha Panda
- क्षेत्र: घरघोड़ा, रायगढ़, छत्तीसगढ़

## लोकल कंप्यूटर पर चलाने के लिए
1. Node.js 18+ इंस्टॉल करें।
2. इस फ़ोल्डर में टर्मिनल खोलें।
3. `.env.example` की कॉपी `.env` नाम से बनाएँ।
4. `.env` में `SESSION_SECRET`, `ADMIN_USERNAME` और `ADMIN_PASSWORD` को अपने सुरक्षित मानों से बदलें।
5. `npm install` चलाएँ।
6. `npm start` चलाएँ।
7. ब्राउज़र में `http://localhost:3000` खोलें।
8. एडमिन पैनल: `http://localhost:3000/admin.html`

## ज़रूरी सुरक्षा नोट
- `.env` में डिफ़ॉल्ट पासवर्ड न रखें; मजबूत पासवर्ड लगाएँ।
- यह एक शुरुआती संस्करण है। सार्वजनिक इंटरनेट पर लगाने से पहले HTTPS, सुरक्षित session store, बैकअप, लॉगिंग, स्पैम/दुरुपयोग सुरक्षा और होस्टिंग कॉन्फ़िगरेशन की समीक्षा करवाएँ।
- समाचार प्रकाशित करने से पहले तथ्यों और संबंधित पक्षों की पुष्टि करें।
- यह पैकेज अपने आप इंटरनेट पर लाइव नहीं होता; डोमेन और होस्टिंग अलग से सेटअप करने होंगे।
